# AlateWeather
weather phenomena heatmap application
An interactive real-time weather mapping system that visualizes global weather patterns including temperature, precipitation, wind, clouds, and storms using dynamic heatmaps and animated wind particle effects.



✨ Features
🗺️ Interactive Weather Mapping

Multi-layer visualization - Temperature, precipitation, wind speed, cloud cover, and storm intensity
Dynamic heatmaps - Smooth color gradients representing weather data intensity
Real-time data - Live weather information fetched from API endpoints
Smooth navigation - Fly to countries, zoom controls, and geolocation support

🌬️ Wind Particle Animation

6,000+ animated particles - Real-time wind flow visualization
Color-coded by speed - Visual representation from slow (cyan) to fast (red) winds
Bilinear interpolation - Smooth wind field sampling for accurate movement
Optimized performance - 60fps canvas rendering with fade trails

⏯️ Timeline Controls

Play/Pause animation - Control weather forecast playback
Frame scrubbing - Navigate through forecast hours with slider
Variable speed - Adjust playback from 0.25x to 4x
Frame navigation - Step forward/backward through timeline

🎛️ Map Controls

Zoom in/out
Reset view to default
Refresh weather data
Locate current position
Toggle layer visibility
